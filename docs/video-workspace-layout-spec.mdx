# 视频工作台布局规范

## 1. 问题定义

当前视频模式在选中镜头后，资产工作流区域占满了主工作台，导致中间镜头内容不可读。

这不是小的样式问题，而是布局层级错误。

用户当前的真实目标是：

1. 先看镜头内容
2. 再管理该镜头资产
3. 最后生成视频

如果资产面板展开后把镜头内容挤没了，工作流就会倒置成：

`先看资产表单 -> 再猜镜头内容`

这会直接破坏使用效率。

---

## 2. 硬性原则

### 2.1 中间镜头内容必须始终可见

无论右侧资产工作流是否展开，中间区域都必须始终保留足够空间展示：

1. 当前镜头标题
2. 镜头基本信息
3. 镜头脚本内容
4. 当前分镜提示词或主分镜图摘要

这是硬约束，不允许被资产区挤掉。

### 2.2 资产区是辅助工作台，不是主舞台

右侧资产区的职责是围绕当前镜头补充资产，不应覆盖或替代镜头主内容。

布局优先级必须是：

1. 中间镜头内容
2. 右侧资产操作
3. 底部结果或历史版本

### 2.3 右侧必须可折叠、可分段、可滚动

资产工作流天然内容多，所以不能一次性全部摊开。

右侧面板必须具备：

1. 分段折叠
2. 内部独立滚动
3. 默认只展开当前步骤
4. 可切换精简模式

---

## 3. 正确的工作台结构

推荐恢复并固定为三栏结构：

1. 左栏：章节/场次/镜头导航
2. 中栏：当前镜头内容主区
3. 右栏：当前镜头资产工作流

其中中栏永远是主区。

### 3.1 左栏

保留：

1. 框架与章节导航
2. 场次树
3. 镜头列表

### 3.2 中栏

中栏必须承担以下主内容：

1. 当前场次摘要
2. 当前镜头卡列表
3. 选中镜头详情
4. 镜头脚本与提示词
5. 镜头状态概览

注意：

右侧再丰富，也不能让这些内容移出主视区。

### 3.3 右栏

右栏只做当前镜头资产工作流，不展示过长正文，不重复展示整批镜头内容。

---

## 4. 右侧资产区的正确展开方式

### 4.1 默认只展开一层摘要

选中镜头后，右侧不应直接把所有资产步骤全部铺开。

默认状态应只展示：

1. 当前镜头摘要
2. 当前风格
3. 资产完成度
4. 当前缺失项
5. 一个主操作按钮

例如：

- 缺角色图
- 缺场景图
- 缺主分镜图
- 缺首尾帧

### 4.2 步骤区使用折叠面板

右侧建议使用 Accordion / Step Sections：

1. 风格
2. 角色资产
3. 场景资产
4. 主分镜图
5. 首尾帧
6. 本次视频使用资产
7. 生成视频

默认规则：

1. 只自动展开当前最需要处理的一步
2. 其他步骤折叠
3. 用户手动展开时不影响中栏布局

### 4.3 每步只显示必要内容

例如“角色资产”区默认不应展示整批历史图全部大图。

应该先显示：

1. 当前已绑定角色图缩略摘要
2. 资产数量
3. 当前作用域
4. “查看全部 / 管理”按钮

只有点开后才进入详情管理。

### 4.4 资产列表要先缩略，再详情

禁止一上来就在右栏渲染：

1. 大图列表
2. 多组空状态卡片
3. 长表单
4. 多个大面积上传区

正确顺序是：

1. 一行摘要
2. 一组缩略图
3. 进入二级详情

---

## 5. 中栏应该怎么展示镜头内容

### 5.1 镜头卡列表保留在中栏上部

用户选镜头时，中栏上方应始终看得到多个镜头卡，方便来回切换。

不要因为右栏操作进入深层资产编辑，就把中栏切成纯空白或只剩标题。

### 5.2 镜头详情固定在中栏主体

选中某个镜头后，中栏主体应显示：

1. 镜头标题
2. 景别 / 运镜 / 时长
3. 动作描述
4. 对白
5. 分镜提示词
6. 视频提示词
7. 当前主分镜图摘要

### 5.3 资产编辑不应替代镜头阅读

如果用户点击“管理角色图”或“管理场景图”，建议：

1. 右栏展开对应资产区
2. 中栏镜头详情保持不变

不要把中栏整个切成资产编辑页。

---

## 6. 推荐的具体布局策略

### 6.1 桌面端宽屏

建议比例：

1. 左栏 `280-320px`
2. 中栏 `minmax(720px, 1fr)`
3. 右栏 `360-420px`

原则：

1. 优先保障中栏
2. 右栏不应无限膨胀
3. 右栏超长内容必须内部滚动

### 6.2 中等宽度屏幕

当空间不足时，应优先压缩右栏，而不是压缩中栏阅读区。

建议行为：

1. 右栏切换成窄模式
2. 只显示当前步骤摘要
3. 详情改为弹层或抽屉

### 6.3 小屏模式

不建议继续三栏并列。

建议改成：

1. 中栏优先
2. 右栏资产管理变成抽屉
3. 用户点击“管理当前镜头资产”后再展开

## 8. 交互补充建议

### 8.1 提供“专注镜头”与“专注资产”两种模式

右侧顶部可以增加一个简单切换：

1. `专注镜头`
2. `专注资产`

行为建议：

- `专注镜头`
  - 右栏只显示资产摘要
- `专注资产`
  - 右栏展开更多步骤

这样能兼顾阅读和制作。

### 8.2 提供“查看全部资产”二级入口

右侧主面板不要承担完整素材库展示职责。

需要时再进入：

- `查看全部角色图`
- `查看全部场景图`
- `查看全部首尾帧`

这些内容更适合弹层、抽屉或二级页。

---

## 9. 结论

这个问题的本质不是“资产面板内容太多”，而是：

`资产工作流被错误地做成了主视区。`

正确修正方向是：

1. 中栏镜头内容始终可见
2. 右栏资产面板固定宽度、内部滚动、步骤折叠
3. 默认只显示资产摘要，不一次性铺满所有步骤
4. 大量资产详情进入二级层，不在主工作台首屏全部展开

只有这样，用户才能一边看镜头内容，一边管理当前镜头资产，而不是在两者之间互相遮挡。

## 生成方法

运行以下命令生成预览图：

```bash
cd backend
python scripts/generate_style_preset_images.py
```

## 注意事项

- 这些图片是**永久保存**的资源文件，不会被更新脚本删除或覆盖
- 图片同时保存到 `backend/manga_outputs/style-presets/` 用于 API 服务
- 数据库中的 `image_url` 字段存储相对路径 `style-presets/xxx.png`
- 前端通过 `/static/manga/style-presets/xxx.png` 访问这些图片

## 更新图片

如需更新某个风格的预览图：

1. 删除对应的 `.png` 文件
2. 重新运行生成脚本
3. 提交更新到 git

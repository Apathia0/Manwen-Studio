# storycanvas-mobile（旧 H5，已冻结）

> **⚠️ 维护状态：已冻结（2026-08）**

本目录为旧版移动端 H5（Vue 3 + uni-app），**仅保留历史与回退用途**，不再新增功能、不再修复缺陷、不再进行日常维护。

## 为什么冻结

依据 `docs/web端对移动端兼容适配改造方案.md` 的 P4 阶段决策：

- React Web（`frontend/`）已通过响应式改造覆盖 **手机、平板、桌面** 全部断点，并具备 PWA 安装能力。
- 旧 H5 的功能已全部迁移到 React Web，路由映射见 `docs/H5-to-Web-路由映射.md`。
- 为降低维护成本与双端漂移风险，正式入口切换后停止 uni-app H5 构建。

## 冻结边界

| 事项 | 状态 |
|---|---|
| 新功能开发 | ❌ 禁止 |
| 缺陷修复 | ❌ 禁止（紧急线上问题经确认后例外） |
| 依赖升级 | ❌ 禁止 |
| H5 构建发布 | ❌ 停止（正式切换后） |
| 小程序专项能力 | ⚠️ 仅当仍需要小程序时，维护对应专项能力（见改造方案 P4） |

## 回退能力

正式切换前，旧 H5 保持 `/h5/` 路径可访问，作为 React Web 的回退方案。确认稳定运行一个发布周期后停用。
